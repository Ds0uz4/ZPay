# Payment Processing Analysis

The Payment Processing Agent analyzes payment systems with focus on:
- Requirements analysis for payment processing scenarios
- Security measures (tokenization, 3D Secure, encryption)
- Compliance standards (PCI DSS Level 1, RBI guidelines, GST reconciliation)
- Payment integrations (gateways, bank APIs, fraud detection)
- Architecture considerations (reconciliation, idempotency, retry logic, refunds)

Assumptions are labeled P-# (e.g., P-1 Jurisdiction: India, P-2 Payment methods: UPI/cards/net banking/wallets). Retrieved `docs/ingested` passages are attached automatically. Cite exact local paths; write `NEEDS-VALIDATION` when evidence is absent.

Studio: run workflow `payment-processing-analysis`, or chat the Payment Processing Agent directly.
